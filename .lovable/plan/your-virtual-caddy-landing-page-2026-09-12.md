# Your Virtual Caddy landing page

## Goal
Create a focused, premium landing page that presents Your Virtual Caddy as a serious golf technology product, with the cinematic course visual as the defining first impression.

## Build
- Replace the placeholder home page with a responsive single-page experience.
- Add a minimal transparent navigation bar with a refined monogram, product name, and understated “Get Started” action.
- Build a full-viewport hero using the generated aerial golf-course image, layered with restrained tonal treatment, subtle course-data markers, strong typography, supporting copy, and one primary CTA.
- Add a concise editorial concept section explaining how course context, conditions, and player tendencies become a clear club decision.
- Add a dark, minimal closing CTA and compact footer.
- Use gentle entrance and scroll-reveal motion, with reduced-motion support.

## Visual system
- Near-black graphite, soft stone, and deep golf green with a restrained lime accent.
- Large editorial sans-serif typography with generous whitespace and sharp, minimal controls.
- Subtle shadows, atmospheric image overlays, fine rules, and no card-heavy feature grid.
- Responsive composition that preserves the cinematic image and clear CTA hierarchy on mobile.

## Technical details
- Define all palette, typography, shadow, and motion values as semantic tokens in the global design system.
- Load the selected web typeface from the document head.
- Add unique home-page metadata and update global product metadata.
- Keep the generated image bundled locally and optimize its rendering as the main visual.
- Verify the finished page in desktop and mobile-sized browser views, then check build and runtime diagnostics.
